Manual test cases

In addition to the automated testing above, we also conducted usability testing with a few potential users who agreed to partake in this testing. We have designed a scenario to evaluate the user experience to simulate the way in which a user would play the game on their own to find out any usability issues. It follows this pattern:

  1. Prepare list of expected actions from the user. This encompasses ease of figuring out how to interact with the UI and how the game works
  2. Launch the game and hand it to the user
  3. Within a single game's duration, observe how user interacts with the game. If the user cannot figure out intutively how to use one of the game features, this problem is noted down. If the user misses one of the crucial details, this is also noted down.
  4. When the game's timer finishes, talk to the user and ask them about any of their frustrations with the game. Note them down. Afterwards, point out any usability issues you have found yourself and confirm them with the user.
  5. Create a list of known usability issues. Show it the user and ask to rank top 5 issues in order of frustration. Note the order down and divide the list into tasks for different areas of the game. Pass the issues of each area to the person who was responsible for developing them.
  6. Close the game and thank the user.
